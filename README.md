# Rillion interactive demo

A public, login-free simulation of a Rillion accounts-payable workflow. It uses fictional Northstar Manufacturing data and is not connected to Demo51 or any production service. The click-through includes To Verify, Invoice Log, approval reporting, and five representative Rillion Analytics views.

Explore the live demo at <https://taste4458.github.io/rillion-demo-site/>.

## Run locally

```sh
python3 -m http.server 4173
```

Open <http://127.0.0.1:4173/>.

## Check the simulation contract

```sh
node check.mjs
```
